# ProofMINT :rocket:
A blockchain app for decentralized certificate verification.

## Getting Started
### Prerequisites   
- Node.js
- npm
- Hardhat
- Metamask
- Infura
- Web3.storage
- React

### Installing
- Clone the repository
- Install the dependencies
```
npm install
```
- Run the app with        
```
npm start
```
